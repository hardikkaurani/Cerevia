## 🛠️ What This PR Fixes

### 1. ⏱️ Study Time — Realistic Hours
- **Before**: `completedModules * 8.1` → 2 lessons showed **16.2 hours** (unrealistic)
- **After**: `completedModules * 1.5` → 2 lessons shows **3.0 hours** (realistic)

### 2. 📊 Labs Submitted — Accurate Count
- **Before**: `completedModules * 3` → 2 lessons showed **6 Submitted** (inflated 3x)
- **After**: `completedModules` → 2 lessons shows **2 Submitted** (real count)

### 3. 🎯 Difficulty Filters — Now Working
- **Root Cause**: Filter buttons used UPPERCASE values (`BEGINNER`, `INTERMEDIATE`, `ADVANCED`) but database stores title case (`Beginner`, `Intermediate`, `Advanced`). The comparison was case-sensitive, so filters never matched any lessons.
- **Fix**: Changed filter values to match database values (title case).
